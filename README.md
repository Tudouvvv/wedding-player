# 婚礼影音播放器

一个为婚礼现场准备的「照片轮播 + 背景音乐 + 同步歌词」程序。单文件、零依赖，本地素材播放完全离线可用；歌单导入功能需要联网。

## 快速开始（推荐：本地服务模式）

歌单导入（网易云 / QQ 音乐）依赖本地小服务转发接口，用下面的方式启动最稳定：

1. 双击「启动播放器.bat」—— 程序自带本地服务（wedding-server.exe，无需安装任何东西），浏览器会自动打开播放器。
2. **第一步「素材与音乐」**：点击「📁 点击选择素材文件夹」，选择存放素材的文件夹（或直接把文件夹拖进去）；需要时用「💿 本地音乐」导入已下载的歌，或展开「高级」粘贴歌单链接 / 登录。
3. **第二步「环节设置」**：先看「🎬 演出预检」——三个环节都为绿色（照片/音乐不为空）才算准备好；再按需调整各环节的停留时长、特效、歌词等。
4. 点击「▶ 开始播放」，按 F 全屏，按 M 切换环节。播放时点「🔒」可锁定界面防误触（点右上角解锁）。

关闭服务 = 关掉弹出的黑色命令行窗口。

> **配置文件持久化**：登录 Cookie、照片文件夹名、模式设置、**导入过的歌单链接**以及**导入的本地音乐文件夹**会自动保存到项目目录下的 config.json。**不保存具体歌曲**：每次启动时读取歌单链接自动重新导入，歌单在音乐平台更新后，下次打开即自动同步最新歌曲；本地音乐文件夹内的文件也会在启动时重新扫描加载（需文件仍在原位置）。照片文件夹需点击重新授权一次；删除 config.json 即恢复全新状态。

## 快速开始（免安装：直接打开）

直接双击 wedding-player.html，用 Chrome / Edge 打开即可。照片、本地音乐、歌词功能完整可用；歌单导入会尝试公共网络通道，可能不稳定（尤其付费歌曲可能无法获取播放地址）。

## 歌单导入（QQ音乐 / 网易云 / 华为音乐）

在设置页「歌单导入」粘贴歌单链接：

| 平台 | 支持的链接示例 |
|---|---|
| 网易云音乐 | https://music.163.com/#/playlist?id=2529983992 、 https://y.music.163.com/m/playlist?id=... |
| QQ音乐 | https://y.qq.com/n/ryqq/playlist/8870296926 、 https://i.y.qq.com/n2/m/share/details/taoge.html?id=... |
| 华为音乐 | 没有公开的网页歌单链接，请用「粘贴歌单文本」方式 |

**华为音乐（或任何没有链接的歌单）**：在手机 App 里打开歌单 → 分享 → 复制文本 → 粘贴到播放器的「粘贴歌单文本」框，一行一首，如：

    体面 - 于文文
    晴天 - 周杰伦

原理与说明：

- 网易云歌单：直接解析曲目并导入，播放时自动获取 128kbps 播放地址（采用 metowolf/Meting 的 EAPI 方案，更稳定），并自动加载歌词。
- 免费歌曲可完整播放；VIP / 付费歌曲会播放 30-60 秒试听片段后自动切下一首（网易云版权限制，未登录 VIP 账号只能试听）。
- 想完整播放 VIP 歌曲：网易云用「📱 扫码登录」；QQ音乐免费歌曲已可直接完整播放（签名方案），VIP 歌曲可粘贴 y.qq.com 的 Cookie（含 uin 与 qqmusic_key 或 qm_keyst）解锁完整播放。
- QQ 音乐歌单：直接解析导入，播放采用 lx-music-api-server 的 Tencent 签名方案（无需登录即可完整播放免费歌曲；VIP 歌曲填 Cookie 后完整播放）。
- 导入的歌单歌曲会自动获取歌词（网易云源）；也可以手动点「🎼 歌词」替换。
- 歌单导入与播放都依赖网络；建议婚礼前提前导入并试听一遍。

## 素材准备

把素材放进同一个文件夹（可含子文件夹，会自动递归扫描）：

| 类型 | 支持格式 | 说明 |
|---|---|---|
| 照片 | jpg / jpeg / png / webp / gif / bmp / avif | 建议 16:9 横图；人像照片请在设置里选「适应屏幕」 |
| 视频 | mp4 / webm / mov / m4v | 与照片放同一文件夹混合轮播；播放视频时自动暂停粒子与音乐，播完恢复 |
| 音乐 | mp3 / wav / ogg / flac / m4a / aac / opus | 自动按文件名排序播放 |
| 歌词 | .lrc | 文件名需与音乐同名，如 song.mp3 对应 song.lrc，自动匹配 |

> 也可以不用 .lrc 文件：在音乐行点「🎼 歌词」，把带时间轴的歌词文字粘贴进去（LRC 格式，如 [00:05.00] 歌词内容）。

### 双语歌词（原文 + 译文）

程序支持「原文大字 + 译文小字」的双语展示，三种来源都会自动合并：

1. **单文件双语 .lrc**：同一句的原文和译文时间戳相同（交错），或写成 `原文 -> 译文` 一行（合并）—— 对应 [163MusicLyrics](https://github.com/jitwxs/163MusicLyrics) 的「交错 / 合并」输出格式。
2. **独立译文文件**：在原歌词旁放一份译文，文件名后缀为 `.trans` / `.tran` / `.translation` / `.tlyric` / `.译文` / `.zh` 等，例如 `song.lrc` + `song.trans.lrc` —— 对应 163MusicLyrics 的「独立」+「分文件保存」。
3. **在线歌曲**（歌单 / 直链）：自动获取网易云、QQ 音乐自带的译文。

> 想批量生成双语歌词：用 163MusicLyrics 搜到歌曲后，歌词类型勾选「原文 + 原始译文」，格式选「交错」或「合并」，保存到对应音乐文件夹即可（保存文件名与音乐同名）。

### 导入本地已下载的音乐（与素材文件夹分离）

在设置页「💿 导入本地音乐」可以把电脑里**已经下载好的音乐**加入播放器，不用拷贝到照片文件夹：

- **📁 导入音乐文件夹**：本地服务模式下选择程序目录内的子文件夹（如 `music/仪式`），其中的 mp3/ogg/flac/m4a 等自动导入，并在 config.json 中记忆、**重启后自动重新加载**（最稳，推荐婚礼前把歌复制到程序目录下再用）；直接双击 HTML 打开时则是用浏览器选任意文件夹，仅当次有效。
- **🎵 选择音乐文件**：任意位置多选音频文件加入列表（当次有效，不会被重新选照片文件夹清掉）。
- 每首歌右下角的「热场 / 仪式 / 尾声」小按钮决定它在哪些环节播放；导入的音乐默认三个环节都播，可按需关闭。

**加密音乐（.mgg / .mflac / .ncm）**：QQ音乐、网易云 VIP「专属格式」下载的文件带版权加密，浏览器无法直接播放，程序会在导入时识别并提示（不会加入列表）。请先用解锁/转码工具（如 GitHub 上的「音钥 MusicKey」）转成 mp3/ogg/flac 后，再把结果放进音乐文件夹导入；或在平台内重新下载标准/高品质（非加密）版本。

### 三种环节的音乐来源：歌单 or 本地（二选一）

每个环节卡片新增「音乐来源」下拉，决定该环节播放哪批音乐：

| 选项 | 效果 |
|---|---|
| 全部（默认） | 歌单歌曲 + 本地音乐一起放（老行为） |
| 歌单 | 只放歌单导入 + 在线直链的歌曲（需网络） |
| 本地 | 只放本地已导入/扫描的音乐（完全离线，最稳） |

选「本地」的环节在启动和切换时**不会再自动导入歌单**；选「歌单」的环节照旧自动导入该环节歌单。

### 在线音乐直链

在「在线音乐（直链）」粘贴可直接播放的音频地址（一般以 .mp3 等结尾）。部分网站（网易云、QQ音乐等）的分享链接不是直链，无法直接播放 —— 请改用上面的「歌单导入」功能。

## 三种环节模式

| 模式 | 默认照片时长 | 默认特效 | 用途 |
|---|---|---|---|
| 🎉 热场 | 4 秒 | 淡入淡出 | 宾客入场前，快节奏轮播 |
| 仪式 | 8 秒 | 缓慢缩放 | 仪式中，可叠加欢迎文字、显示歌词 |
| 🎊 尾声 | 6 秒 | 缩放淡入 | 宴席期间继续播放 |

每个模式都可单独设置：**素材文件夹**（程序目录下的相对路径，如 warmup 或 warmup/photos；留空共用上方素材）、**歌单链接**（本环节专用，每行一个）、**本地音乐文件夹（本环节专用）**、照片停留时长、**照片随机轮播**（整轮洗牌、一轮内不重复）、**切换特效（可多选，每张照片随机换一种）**、**粒子特效（可多选，随机切换）**、叠加文字（仪式环节可显示「欢迎参加我们的婚礼」等）、是否显示歌词、是否随机播放音乐。每首歌右下角的「热场 / 仪式 / 尾声」小按钮决定它在哪些环节播放（金色 = 开启）。播放时按 S 可随时切换随机播放。

> **每个环节的「本地音乐文件夹」**：热场/仪式/尾声可各自指定一个独立的本地歌曲目录（本地服务模式下选程序目录内的文件夹，如 `music/仪式`）。**设置了专属目录的环节只播该目录的音乐**；没设置专属目录的环节，才回退使用上方「💿 导入本地音乐」导入的通用目录（及素材文件夹里的音乐）。目录会写入 config.json，启动与切换环节时自动加载；需要改到其他环节的歌可在音乐列表逐首调整标签。

### 粒子特效（tsparticles）

照片播放时可在画面上叠加飘动粒子，默认：热场=彩带飘落、仪式=星光闪烁、尾声=爱心飘升。每个环节可单独选择 11 种：关闭 / 彩带 / 爱心 / 星光 / 花瓣 / 雪花 / 火焰火星 / 泡泡上升 / 萤火虫 / 金色星光 / 气球上升（用 tsParticles v2.12 实现，已内置本地文件 tsparticles.min.js，离线可用；v3 在部分环境存在绘制兼容问题，已改用 v2）。

## 现场使用建议

- 提前彩排一次：用「启动播放器.bat」启动，把窗口拖到投影仪屏幕 → F 全屏 → 播放测试音乐。
- 歌单提前导入并试听：确认每首歌都能播放、歌词正常。
- 开场前用「热场」模式循环照片；仪式时按 M 切到「仪式」。
- 若某首歌播放失败，程序会自动跳过（歌单歌曲会重新获取地址重试一次）。

## U 盘 / 离线现场部署（酒店等无网络场景）

婚礼现场常无网络，本程序按「离线优先」设计：照片、本地音乐、.lrc 歌词、粒子特效全部本地运行，**不联网也能完整播放**。只有「歌单导入 / 在线直连 / 扫码登录」需要网络 —— 现场请勿依赖这些功能。

### 拷到 U 盘需要哪些文件

把整个程序文件夹拷到 U 盘即可，其中**必须包含**：

| 文件 / 目录 | 说明 |
|---|---|
| `wedding-player.html` | 播放器主体 |
| `tsparticles.min.js` | 粒子特效（本地库，必须与 HTML 同目录） |
| `wedding-server.exe` | 本地服务（自包含单文件，无需安装 .NET）；若丢失会回退用 Python，现场不推荐 |
| `启动播放器.bat` | 双击启动入口 |
| `config.json` | 已保存的设置（全部为相对路径，换电脑 / 换盘符都不受影响） |
| `photo/` `music/` | 你的照片与音乐 |

> `tools/`（含 ffmpeg，约 76MB）只用于把 H.265 视频转码成 H.264，**播放用不到**，可不上 U 盘以省空间；视频请在出发前转好再拷入。

### 现场步骤

1. 到酒店电脑，插入 U 盘，**先把整个文件夹拷到电脑本地磁盘**（直接插着 U 盘运行，可能因 U 盘慢或被拔而卡顿 / 中断）。
2. 双击 `启动播放器.bat`，会自动打开浏览器播放器。
3. 检查「② 环节设置」的**演出预检**三格是否全绿；标红说明该环节照片或音乐为空。
4. 把浏览器窗口拖到投影屏 → 按 F 全屏 → 按 M 切换环节。
5. 建议把三个环节的「音乐来源」都设为**本地**，彻底不依赖网络（config.json 中 `modeMusicSource` 全为 `local`）。

### 出发前务必实测

- **杀毒 / SmartScreen 拦截**：`wedding-server.exe` 未签名，在陌生电脑首次运行可能弹「Windows 已保护你的电脑」，需点「更多信息 → 仍要运行」；部分杀软会直接隔离。**请提前在一台干净电脑上试跑一次**，或把该 exe 加入杀软白名单。
- **浏览器**：用 Edge 或 Chrome（Win10/11 自带 Edge）。
- **视频编码**：H.265/HEVC 视频浏览器可能只出声不出画，请提前用「转码视频.bat」转成 H.264 再放入素材。
- 备一份**离线备份**：U 盘一份、电脑本地一份。

## 常见问题

Q：点击选择文件夹没反应？
部分浏览器 / 环境会禁用高级文件夹选择。此时点击素材区下方「🖼 没弹出选择窗口？点这里用系统窗口选文件夹（兼容模式）」按钮，会使用系统原生窗口选择文件夹，对所有浏览器都有效。

Q：每次打开都要重新选文件夹？
浏览器出于安全限制，本地文件无法永久记住。用 Chrome/Edge 时，第一次授权后下次打开只需点击一下文件夹区域重新授权即可（会记住上次的文件夹）。

Q：歌单导入失败或一直转圈？
- 确认网络可用；确认用的是「启动播放器.bat」启动（本地服务模式最稳定）。
- 网易云歌单若「需要登录」，多为私密歌单，请改为公开歌单再试。
- 若提示没有 Python：正常情况不需要 Python；该提示只在 wedding-server.exe 丢失时出现，重新拷贝完整文件即可。

Q：为什么有的歌播放不了？
- 网易云免费歌曲可正常播放；VIP/付费歌曲为约 45 秒试听片段，播完自动切下一首。
- QQ 音乐导入的歌在网易云上未收录的，会显示「未匹配」。
- 若使用免安装（直接双击 HTML）模式，付费歌曲可能无法获取地址，请用「启动播放器.bat」启动。

Q：歌词不显示？
- 检查 .lrc 文件名是否与音乐同名；歌单歌曲会自动获取歌词。
- 检查对应模式的「显示歌词」是否开启（快捷键 L）。

Q：照片被裁掉了？
在设置页「照片填充方式」选择「适应屏幕（不裁剪）」。

Q：想整体换素材或重新开始？
删除项目目录下的 config.json 后重启，就是全新状态；或者重新选择照片文件夹、重新导入歌单即可（会自动更新配置文件）。

Q：导入本地音乐时提示 .mgg / .mflac 加密无法播放？
那是 QQ音乐/网易云 VIP 的「专属格式」下载，带版权加密，浏览器播不了（也不会被加入列表）。请用「音钥 MusicKey」等解锁工具转成 mp3/ogg/flac 后再导入；或在该平台内重新下载标准/高品质版本。程序会记住你导入过的音乐文件夹，转码结果放回原文件夹后重新导入即可。

Q：本地导入的音乐每次打开还在吗？
本地服务模式（启动播放器.bat）下，「📁 导入音乐文件夹」选择的文件夹会写入 config.json，重启自动重新加载；「🎵 选择音乐文件」和直接双击 HTML 打开时，受浏览器安全限制只当次有效，需重新选择/导入（与照片文件夹同理）。

Q：某一环节想只听本地音乐、不播歌单？
在「② 三种环节模式」里把该环节的「音乐来源」选成「本地」，该环节就不会再自动导入/播放歌单在线歌曲；改成「歌单」则反之，选「全部」恢复两者都播。
