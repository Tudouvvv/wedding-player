📖 点击查看：如何获取 QQ音乐 Cookie（三种方法）
方法一（最稳，不用插件）：
1. 打开 y.qq.com 并登录（右上角有头像才算登录成功）
2. 按 F12 → 点「应用 Application」标签
3. 左侧展开「Cookie」→ 点 https://y.qq.com
4. 右侧表格里找到 uin 和 qqmusic_key（或 qm_keyst）两行
5. 双击值复制，粘贴成这种格式：
  uin=o123456789; qqmusic_key=xxxxxxxx

方法二（Cookie Editor 插件，一键复制全部）：
1. 浏览器装「Cookie Editor」扩展（应用商店搜）
2. 打开 y.qq.com 并登录 → 点插件图标 → 点 Copy → 全部粘贴

方法三（F12 网络请求）：
1. F12 → 「网络 Network」→ 确认左上角过滤框是「全部」状态
2. 按 Ctrl+F5 强制刷新
3. 找到名称 y.qq.com、类型 document的请求（不是 stat6.y.qq.com 统计请求）
4. 「标头 Headers」→「请求标头」→ 复制 Cookie: 整行值

在浏览器打开 music.163.com 并登录 → F12 → 应用(Application) → Cookie → 复制 MUSIC_U=... 粘贴到这里，VIP 歌曲即可完整播放（仅保存在本机）。

歌单导入需联网。QQ / 网易云歌单直接使用对应平台的播放源；用「启动播放器.bat」启动更稳定。
